# CAL-140 · Modelo de tema, tokens e leitura no servidor

## Objetivo
Criar o contrato de tema (`businesses.theme`) e a camada de tokens CSS da página pública, sem
mudar nada visualmente para quem não escolheu tema (o visual atual vira o "Noturno").

## Decisões
- **Chaves em inglês** (CLAUDE.md: código e banco em inglês). O backlog escreve `mostrar`,
  `formato`, `visivel`, `ordem`, `"claro"|"escuro"`; no JSON ficam `show`, `shape`, `visible`,
  `order`, `"light"|"dark"`. A interface continua em português.
- `theme` é **opcional** (`null` = padrão). Sem migração de dados: o servidor resolve
  `theme ?? padrão Noturno` e usa `accent_color` como `palette.primary` quando o tema não tem
  cor própria. Ao salvar um tema, `accent_color` é atualizado junto (compatibilidade com o
  painel, OG, e-mails).
- Versão no JSON (`version: 1`). Tema inválido ou de versão desconhecida → padrão, nunca erro.
- **AA garantido pelo sistema**: o tema guardado pode ter qualquer cor válida, mas os tokens
  saem de `resolveTheme()`, que corrige texto/botão/links até passar (4,5:1 texto, 3:1 para
  bordas/elementos grandes). O dono não consegue publicar combinação ilegível.

## Contrato (v1)
```ts
{
  version: 1,
  templateId: string,            // "noturno" | ... (registro na Sprint 16)
  paletteId?: string,            // paleta pronta usada como base (CAL-141)
  palette: {
    mode: "light" | "dark",
    primary: "#RRGGBB",          // cor de destaque (botões)
    secondary?: "#RRGGBB",
    background: "#RRGGBB",
    surface: "#RRGGBB",          // cartões, faixas alternadas
    text: "#RRGGBB",
    muted?: "#RRGGBB",           // texto secundário (opcional; o Noturno usa #C9C4B9)
  },
  fontPairId: string,            // CAL-142
  radius: "square" | "soft" | "round",
  density: "compact" | "comfortable",
  logo: { show: boolean, shape: "square" | "round" | "free" },   // CAL-143
  sections: { id: SectionId, visible: boolean, order: number }[] // CAL-144
}
```

## Tokens CSS (raiz da página pública)
`--c-primary`, `--c-primary-fg`, `--c-primary-hover`, `--c-primary-soft`, `--c-secondary`,
`--c-bg`, `--c-surface`, `--c-surface-2`, `--c-text`, `--c-sub`, `--c-border`, `--c-link`,
`--radius`, `--radius-sm`, `--font-display`, `--font-body`. Mantém `--accent`/`--accent-fg`
como apelidos (fluxo de agendamento até o CAL-150).
Tailwind: `@theme inline` com `--color-t-*: var(--c-*)` para usar `bg-t-bg`, `text-t-sub` etc.
